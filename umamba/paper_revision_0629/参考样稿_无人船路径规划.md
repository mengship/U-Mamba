基于A*与动态窗口法的无人船路径规划*

摘要：海岸线突袭任务要求无人船在复杂的海岸环境中完成精确的定点突袭。海岸区域地形多变，存在礁石、浅滩等静态障碍物与海上漂浮物等动态障碍物，同时任务时间有严格要求。因此，无人船实时、安全、准确的路径规划非常重要。本文针对当前路径规划兼顾全局寻优、实效性和安全性的难题，基于A*算法和动态窗口法（DWA）提出了全局搜索与局部优化相融合的方法：A*算法提供静态环境下全局最短路径，路径节点之间使用改进的DWA进行局部路径避障优化。通过引入动态指数衰减加权的启发式函数改进A*算法，降低了全局路径规划的运行时间和探索空间；通过引入动态障碍物航向角和无人船预测轨迹航向角的夹角评价子函数和基于Logistic函数的距离评价子函数来改进DWA，增强了局部避障中的实时反应能力。仿真结果表明，融合算法在海岸线突袭任务中能够实时搜索到全局近优解，有效应对了静态和动态障碍物的影响，显著提升了无人船在复杂海岸线环境中的任务完成效率和稳定性。

**Path planning of unmanned ships based on A\* and dynamic window approach (DWA)**

**Abstract:** The coastline raid task requires an unmanned surface ship to carry out precise, fixed-point raids in a complex coastal environment. The terrain of the coastal area is highly varied, with static obstacles such as reefs and shoals, as well as moving obstacles like floating objects at sea. Moreover, the task must be completed within a strict time frame. Therefore, real-time, safe, and accurate path planning for the unmanned surface ship is crucial. To address the challenge of balancing global optimization, efficiency, and safety in path planning, in this paper we propose a method that integrates global search and local optimization, based on the A* algorithm and the Dynamic Window Approach (DWA). The A* algorithm computes the global shortest path in a static environment, while the improved DWA optimizes local path obstacle avoidance between path nodes. The A* algorithm is enhanced by incorporating a heuristic function with dynamic exponential decay weighting, which reduces the running time and exploration space for global path planning. Additionally, the DWA is improved by introducing an evaluation function based on the angle between the heading of dynamic obstacles and the predicted trajectory of the unmanned surface ship, as well as a distance evaluation function based on a logistic curve, which enhances the real-time responsiveness of local obstacle avoidance. Simulation results demonstrate that the proposed hybrid algorithm can search for a near-optimal global solution in real-time, effectively handle both static and dynamic obstacles, and significantly improve the task completion efficiency and stability of the unmanned surface ship in complex coastal environments.

**Key words:** Coastline raid; A* algorithm; Dynamic window approach; Path planning

随着无人船技术的快速发展，其在军事、救援、环境监测等领域的应用日益广泛，海岸线环境突袭任务是其中的一个重要部分。海岸线突袭任务要求无人船在复杂的海洋环境中执行精确的定点攻击，因此路径规划和避障能力面临严峻的挑战。海岸线区域地形复杂，既有狭窄水域和港湾等特殊地形，也有礁石、浅滩和岛屿等静态障碍物，这些都增加了路径规划的难度。海上环境中还存在其他船只和漂浮物等动态障碍物，要求无人船具备实时避障能力。同时，突袭任务对时间有严格要求，无人船需要在确保安全的前提下快速地完成任务。所以，如何设计高效的路径规划算法，以应对海岸线复杂环境和多变障碍物的影响，成为研究的重点。目前，路径规划算法主要分为全局路径规划与局部路径规划两类。全局路径规划关注无人船从起始点到目标点的整体路径设计，依赖于静态环境信息；而局部路径规划则是在无人船运行过程中，针对动态环境和障碍物进行实时的路径调整，以确保行驶安全和效率。在海岸线突袭任务中，既需要高效的全局路径规划，又要具备强大的局部避障能力，才能有效应对静态和动态障碍物的挑战。许多研究者针对路径规划问题提出了多种改进算法，其中A*算法、动态窗口法（DWA）以及融合两种算法的方法是常见且有效的路径规划方法。

全局路径规划是在已知地图的情况下计算从起点到目标的最佳路径，常见的全局路径规划算法包括：Dijkstra算法[1]、RRT算法[2][3]、A*算法[4]、遗传算法[5]等。在搜索空间较大并且障碍物复杂时，A*算法需要大量的计算资源，尤其是当目标点距离较远时，搜索过程需要遍历大量的节点，导致计算效率低下。Changgeng Li等人通过结合双向搜索策略和指数衰减启发式函数，降低了传统A*算法在大规模地图和复杂障碍物环境中的计算效率问题[6]。Zhi Lin等人提出了一种改进的A*算法，通过在障碍物周围设置冗余安全空间，提高路径的安全性。引入转弯成本和冗余拐点优化策略，降低拐点冗余[7]。王洪斌等人通过目标成本函数和自适应优化策略，缩短了路径长度并降低了转折角度。同时，结合改进动态窗口法和预瞄偏差角追踪法在动态复杂环境中实现了局部避障与动态目标追踪[8]。朱泺谕等人引入了奖惩机制，以优化路径选择，减少不必要的路径弯曲[9]。张伟民等人结合跳点搜索法提出优化修剪规则的有限跳点搜索法，以提高A*算法在室内巡检机器人路径规划中的效率和性能[10][11]。张浩杰等人在传统A*算法的基础上，将能耗值作为节点之间的通行成本，以能耗运动基元集中定义的节点连接关系进行节点扩展，获得一条全局能耗最优路径[12]。宗敬文等人提出引入地图环境信息，重新定义了含有权重的代价函数和启发函数的评价函数，平衡算法的搜索效率和精度。并将搜索方向缩小到5个方向[13]。

尽管A*算法在静态环境中表现出色，能够高效地找到最优路径，但在面临动态障碍物：如其他船只、漂浮物等的干扰，A*算法无法实时调整路径，导致其适应性和实时性较差。而局部路径规划算法，能够实现在动态环境中实时调整路径，躲避障碍物，并确保路径的安全性和可行性。常见的局部路径规划算法包括：人工势场法[14]、动态窗口法等。1997年Fox等人提出动态窗口法（DWA）以来[15]，大量研究在其基础上不断改进优化，以适应复杂多变的应用场景。Petter通过结合DWA和控制Lyapunov函数的收敛性框架，解决了传统DWA在动态环境中的收敛性问题。改进的DWA能够有效地处理动态环境中的障碍物，提高导航的稳定性和安全性[16]。王永雄等人根据机器人与障碍物之间的距离以及障碍物密集度自动调整目标函数中的权值，从而适应环境的动态变化，优化运行速度和路径[17]。Lee等人提出了一种结合有限记忆滤波与动态窗口方法通过估算障碍物的整体分布规避动态障碍物[18]。Matej等人提出了一种结合深度学习和DWA的方法。通过神经网络能够根据机器人周围的障碍物分布动态预测DWA成本函数的权重，增强对动态环境的适应性[19]。Zhiqiang Jian等人提出了一种用于差速轮式机器人的长时动态窗口局部规划方法。该方法利用长时动态窗口生成初步轨迹，随后通过图优化进行调整。结合时间变化距离场和弹性带模型预测控制，生成符合运动学约束并确保安全的路径，引导机器人顺利到达目标[20]。Yasuda等人提出了一种改进的动态窗口法，通过确定性采样，在每个输入候选上预先近似末端状态分布，生成确定性样本路径，从而提升安全性并减少计算开销[21]。张伟龙等人通过改进距离评价函数并引入规则评价函数，结合国际海上避碰规则（COLREGS），提高USV在复杂环境中的避碰能力，确保航行安全[22]。Jinyu Fu等人结合动态窗口方法和概率路线图（PRM），生成动态环境中的可行路径, 适应动态环境中的变化，提高路径规划的鲁棒性[23]。王洪斌等人提出引入差分动态窗口的概念，通过结合多目标优化和动态窗口方法，提高移动机器人在复杂动态环境中的路径规划性能[24]。

但是局部路径规划算法仅关注当前局部环境，缺乏全局视野，忽略长远全局路径，致使规划路径陷入局部最优，甚至陷入局部死循环，无法抵达目标。因此，结合全局路径规划和局部路径规划的混合方法，可以更有效地应对海岸线等复杂动态环境中的路径规划问题。迟旭等人通过舍弃三个搜索方向，保留五个搜索方向，并通过当前点与目标点的距离与起点到目标点的距离的比值动态调整启发式函数的权值，并将全局路径信息融入DWA算法，从而提高路径规划的精度和效率[25]。Di Wang等人通过使用改进的A*算法减少路径长度和转弯次数生成全局路径，并通过在圆周上均匀分布测试点来选择总势场强度最小的方向实现实时避障，同时采用偏移引导确保遵守国际海上避碰规则。但其复杂性增加、计算资源需求较高[26]。Sen Han等人结合了非均匀Theta*算法和改进的动态窗口方法（IDWA），用于无人水面船（USVs）的路径规划。通过优化路径平滑性和动态适应性，提高USV在复杂动态环境中的路径规划性能[27]。Haixu Yang等人利用从当前点到目标点的曼哈顿距离作为启发式函数规划路径，改进DWA算法，通过增加转向角度评价函数，避免产生过大的转向角，提升路径的平滑性和可行性[28]。Leng Han等人提出采用障碍物数量和网格数相结合的自适应指数系数作为启发式函数的权重规划全局路径。并结合DWA算法进行局部路径规划，以实现动态障碍物的避障[29]。Wei Guan等人通过引入COLREGS规则来优化A*算法搜索空间，减少局部优化陷阱，并利用深度Q网络（DQN）训练DWA目标函数的权重系数，以提高避碰路径的安全性和合理性。但该算法使系统复杂性增加，结合多种算法使得实现和维护更具挑战性；深度强化学习方法需要大量计算资源和时间，限制了实时应用；算法对环境的依赖性较强，环境变化需要重新训练[30]。唐炜等人提出了一种改进的A*算法，通过总路径节点数动态调整权值，平衡实际路径代价和估算路径代价。对于DWA算法，通过动态调整避障阈值并引入动态障碍物评价函数，以提升避障的实时性和灵活性[31]。邹文等人通过提高栅格分辨率，显著提高了探索效率，同时优化了路径中的拐点。对于DWA算法，增加了刹车等待和跟随两个运动状态，根据障碍物的动态位置进行避障[32]。孙岩霆等人利用节点到目标点的欧氏距离和全局已知障碍物数量动态调整启发式函数权值，提高算法的搜索效率。同时引入路径节点转角角度削弱策略，减少路径的曲折度。对于DWA算法，增加全局路径偏离评价因子和转向角速度评价因子，以进一步提高路径规划的避障能力[33]。赖荣燊等人将8自由度探索空间优化为5自由度探索空间，根据当前节点与目标节点的距离动态调整启发式函数，从而提高路径搜索的效率和精度。对于DWA算法，引入全局路径偏离距离评价函数，避开障碍物[34]。王彬等人利用正态分布构造衰减函数来动态调节启发函数。DWA算法通过动态调整障碍物距离评价子函数与其他评价子函数的权重比重，从而提高避障能力[35]。郁洲等人利用DQN算法结合多智能体的强化学习环境特性，在传统DQN算法的基础上，添加一个结构相同、参数不同的网络，分别对Q实际值和估计值进行更新来实现价值函数的收敛[36]。Tianci Qu等人提出了一种结合DWA和安全强化学习框架的路径规划方法，以提高自主水面航行器在复杂海洋环境中的安全性、样本效率和运动学性能[37][38]。Hub Ali等人提出了基于特征选择的决策模型，用于固定翼无人机在复杂地形上的全球和局部路径规划。该方法通过特征选择从点云地图中提取特征，并利用A*多向规划器生成最优的全球路径[39]。随后又提出了自主船舶导航的安全增强碰撞避免技术，该技术在复杂静态和动态约束下进行全球和局部导航规划，避免与海岸附近水下障碍物发生潜在碰撞[40]。傅汇乔等人基于深度强化学习的六足机器人运动策略，针对复杂的非结构离散环境。通过深度确定性策略梯度（DDPG）算法与优先经验重放机制加速训练，使机器人能够高效平稳地从起始点运动到目标区域[41]。

**1**　无人船路径规划

1.1　改进的A*算法

传统的A*算法[42]是一种基于启发式搜索的最短路径算法，它结合了贪婪算法和Dijkstra算法的优点，能够在复杂环境中寻找最短路径。A*算法使用以下公式来计算每个节点的代价：

​                               f\left(n\right)=g\left(n\right)+h\left(n\right)

  是从起点到当前节点  的实际代价，即路径的实际长度；

 h\left(n\right)=\ \sqrt{{\left(x_{goal}\! -x_{agent}\! \right)}^{2}+{\left(y_{goal}\! -y_{agent}\! \right)\! }^{2}}

A*算法通过不断评估每个节点的  值，选择最小  的节点进行扩展。传统的A*算法在处理大规模的海岸线场景中，面临效率低下的问题。海岸线环境的空间广阔且水域复杂，包含多个静态障碍物，这使得计算量急剧增加，导致算法的搜索效率显著降低。本文对A*算法从调整探索空间、启发函数的动态加权和路径节点与拐点优化三个方面进行改进。

（1）调整探索空间

通过调整8自由度的动作探索距离，能够减少路径搜索过程中需要考虑的栅格数量，从而降低计算量和搜索复杂度。在实际操作中，探索行为的调整是动态的，当算法在当前的探索距离下遍历所有可能的节点后，仍然无法找到一条从起点到目标点的可行路径时，触发调整机制，算法会降低1个栅格的动作距离来提高栅格地图的分辨率，以便更细致地探索潜在的路径。在原始的100×100的地图中，采用8个方向的动作进行搜索，设定一个5个栅格的探索距离来减少搜索空间的大小，将原始的100×100栅格地图优化为20×20的栅格地图。这种调整能够有效减少搜索过程中不必要的节点探索，提高路径规划的计算效率，同时保持较好的路径质量。

（2）启发函数的动态加权

本文采用的改进的A*算法公式如下：

\left\{\begin{gathered}f\left(n\right)=g\left(n\right)+\alpha h\left(n\right) \\ \alpha =1+e^{ch(n)}\ \ \ \ \ \ \ \ \ \ \ \ \  \\ c=-\frac{1}{D_{dist}}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \end{gathered}\right.

其中，n是当前的节点，g\left(n\right)是从起点到当前节点n的实际代价，h\left(n\right)是从当前节点到目标节点的启发式估计代价，α是动态指数衰减的加权因子，c为动态调整因子。 c可以根据起始点到目标点的距离来计算，控制启发式加权的强度。D_{dist}是从起始点到目标点的欧式距离，c的值随着距离的变化而变化，从而确保在不同的场景中，算法的行为和搜索性能保持一致。此时，\mathrm{\alpha }h\left(n\right)的加权作用会适应不同的场景与任务，避免了固定c值导致的过于局部或过于广泛的搜索问题。
引入动态指数衰减的加权的启发式函数，目标是使得加权后的启发式值\mathrm{\alpha }h\left(n\right)大于原本的h\left(n\right)，从而加快算法向终点的探索。这一加权函数的设计不仅加速了终点附近的搜索过程，还能在保持较快的终点探索速度的同时，确保路径的端点位置向外扩展的性能。随着启发式值的增大，算法会更倾向于优先探索靠近终点的区域，但同时，由于加权的指数衰减变化，它也兼顾了在更广阔区域内扩展路径的能力，避免过早聚焦在终点附近，保证了算法的全局搜索能力和路径的合理性。这种方法有效平衡了终点快速探索和全局路径扩展的需求，从而提高了路径规划的效率和精度。在狭窄水域、港湾等特殊地形中，终点往往会被包围在内，导致传统路径规划算法在搜索过程中需要探索大量无效节点，从而降低搜索效率。动态加权启发式函数使启发式函数权重能够随搜索过程动态调整，在搜索初期α较大，算法更倾向于快速向目标节点探索，减少在无效区域的搜索。在接近目标时α逐渐衰减，算法更注重实际代价g\left(n\right)，确保路径的合理性，避免在无效区域探索。如下所示左图为传统A*算法的探索节点数量，右图为改进A*算法的探索节点数量。

（3）路径节点与拐点优化
在调整探索空间探索地图时，尽管计算效率得到了提升，但由于探索距离过大，往往导致规划出的路径不够精确，尤其是在复杂水域环境中，这种路径误差会显得更加显著。为了解决这一问题，在路径规划过程中，若当前节点与回溯两个节点之间的连线经过静态障碍物，则需通过最小化探索空间的方式，重新计算这两个点之间的最短路径，确保规划路径的准确性。相反，如果连线未与障碍物相交，则可以跳过这一过程，直接沿原路径继续规划，从而避免不必要的计算开销。

这种机制有效避免了探索中的路径误差问题，同时兼顾了计算效率与路径精度，在保证实时性的同时，提高了路径规划的可靠性。通过动态调整探索空间，算法能够在不同场景中灵活适应，提高路径规划的精度与有效性。

图4　路径拐点优化示意图

拐点优化是一种通过减少路径曲折度并提高路径效率的策略。在该方法中，首先判断当前点与第二个点的连线是否穿过静态障碍物。如果不穿过障碍物，则跳过第一个点，直接连接当前点与第二个点，并继续判断第三个点，以此类推。若连线穿过障碍物，则将当前点移至最后一个未穿越障碍物的点，并继续优化后续路径。这一策略通过减少路径中的不必要转弯，使得路径更加平滑和直线化，同时保证路径不与障碍物相交，提升了路径的效率和可行性。

表1　无人船模型参数

水面无人船的运动学模型是用于描述无人船在水面上运动规律的数学框架[43]，本文以美国的SeaRobotics-USV为对象进行研究，无人船采用简化的运动学描述方法，忽略船舶的垂向运动，仅考虑水面上的二维运动并将船体简化为一个质点。水面无人船的运动学模型将无人船的运动状态通过位置、速度和航向角等变量在二维坐标系下进行描述，坐标轴指示船体的纵向和横向位置，航向角则定义船头与参考方向之间的夹角。无人船的线速度和角速度是控制其前进方向和转弯的关键参数。基于运动约束生成可行的速度空间并在障碍物环境中生成运动轨迹。
水面无人船的运动学模型通过简化的单质点模型来近似描述。船体的运动由线速度v、角速度ω、线加速度a和角加速度β参数控制。线速度控制船体的前进速度，角速度则描述船体的转向行为。航向角{\theta }_{t}控制船体的前进方向，t是当前时间。水面无人船运动学模型基于二维坐标系进行建模：

x_{t}=x_{t-1}+v\ \times \ \cos{{\theta }_{t}}\ \times \ ∆t
y_{t}=y_{t-1}+v\ \times \ \sin{{\theta }_{t}}\ \times \ ∆t
{\theta }_{t}={\theta }_{t-1}+\omega \ \times \ ∆t\ \ \ \ \ \ 

无人船速度采样：

\left(v,\ \omega \right)=\ \left\{v\ \epsilon \ \left(v_{min},\ v_{max}\right),\ \omega \ \epsilon \ ({\omega }_{min},\ {\omega }_{max})\right\}
\left(a,\beta \right)=\ \left\{a\ \epsilon \ \left(a_{min},\ a_{max}\right),\ \beta \ \epsilon \ ({\beta }_{min},\ {\beta }_{max})\right\}\ \ 

考虑到无人船的动力系统通常只有有限的控制方式，在运动过程中其运动自由度受到约束，在一个时间间隔∆t内实际能到达的速度为:
\left(v,\ \omega \right)=\ \left\{\begin{gathered}v\ \epsilon \ \left(\max{\left(v_{min},\ v\ +a_{min\ }\times \ ∆t\right)},mi\operatorname{n}{\left(v_{max},\ v+a_{max\ }\times \ ∆t\right)}\right)\ \ \ \  \\ \ \ \omega \ \epsilon \ (\max{\left({\ \omega }_{min},\ \omega \ +{\beta }_{min\ }\times \ ∆t\right)},\ min⁡({\ \omega }_{max},\ \omega +{\beta }_{max\ }\times \ ∆t))\end{gathered}\right.

轨迹评价函数：
G_{\left(v,\ \omega \right)}=\ \alpha \times {heading}_{\left(v,\ \omega \right)}+\beta \times {distance}_{\left(v,\ \omega \right)}+\gamma \times {velocity}_{\left(v,\ \omega \right)}

{heading}_{\left(v,\ \omega \right)} 是方位角评价子函数，表示模拟轨迹末端的朝向与目标位置的航向角之间的角度差异；{dist}_{\left(v,\ \omega \right)}是障碍物评价子函数，表示模拟轨迹与障碍物之间的最小距离；{velocity}_{\left(v,\ \omega \right)}是速度评价子函数，表示模拟轨迹的速度大小。参数α,β,γ是分别对应方位角、障碍物距离和速度的加权系数，用于调整各项指标的影响程度。此评价函数综合考虑轨迹的朝向、障碍物避让和航行速度，从而筛选出最优的航行轨迹。
本文提出了一种改进的动态窗口法，以海岸线突袭任务为背景，根据动态障碍物的速度、航向角和角速度进行轨迹预测，计算无人船预测轨迹与动态障碍物的最短距离和无人船预测轨迹到静态障碍物的最短距离。距离评价子函数基于Logistic函数，计算两者最短距离的代价值，该函数使不同量级的最短距离被归一化到一个统一的、易于比较的范围。函数随着最短距离的增加，代价相应提升。参数-c调节函数斜率使d_{min}-d_{limit}附近的变化极为敏感，能够精准捕捉最短距离在该关键阈值附近的微小变动，这种非线性映射关系使得该评价函数能够更有效地反映最短距离的变化对整体评价的影响。

图5　改进DWA算法示意图

同时，引入无人船预测轨迹末端航向角与动态障碍物的航向角的夹角评价子函数{angle}_{\left(v,\ \omega \right)}。当航向角夹角差异越大，表示两者的相对运动方向差异越大，碰撞的风险就越低，评价值越高。通过将这两种评价子函数结合，改进后的动态窗口法能够更精准地避开动态障碍物，同时快速地调整航向，确保无人船能够安全、快速地到达预定目标。
改进后的动态窗口法轨迹评价函数：

{distance}_{\left(v,\ \omega \right)}^{\ast }=\ \left\{\begin{gathered}K\times (\ \frac{1}{1+e^{-c\times \left(d_{min}-d_{limit}\right)}}-\frac{1}{2}\ )\ \ \ \ \ \ \ \ if\ {dist}_{\left(v,\ \omega \right)}^{·}\geq D \\ -inf\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ if\ {dist}_{\left(v,\ \omega \right)}^{·}\lt D\end{gathered}\right.

其中{distance}_{\left(v,\ \omega \right)}^{\ast }是新的距离评价子函数，K是常数，用于调节评价函数值的幅度，d_{min}是无人船到障碍物的最短距离，d_{limit}是障碍物的最短安全距离避障半径, D是障碍物的最短危险距离避障半径。

3　总结
本文提出的融合改进A*算法和改进DWA的路径规划算法并引入重规划机制，有效解决了单一算法在复杂环境中的不足，显著提高了路径规划的效率、优化了路径精度，显著提升了无人船在海岸线定点突袭任务中的效率和安全性。该算法在考虑海岸线特有的复杂地形（如狭窄水域、港湾、礁石、浅滩和岛屿等静态障碍物）以及动态障碍物（如其他船只、漂浮物等）的基础上，优化了路径规划与避障能力，能够确保无人船在复杂环境中稳定执行任务。通过改进A*算法的启发式函数，算法在路径搜索中有效减少了探索节点数量，大幅降低了全局路径规划的计算时间。而改进的DWA在局部路径优化中能够实时调整速度和航向，避免过度计算和冗余路径，实时避障，增强了无人船在复杂海岸线环境中的适应性，尤其在面对变化的障碍物（如移动的船只和漂浮物）时，能够持续保持稳定的航行状态，避免了因避障过度或路径选择不当导致的航行失败。本文还特别考虑了无人船的运动约束，如速度、加速度、航向角度和转弯半径等，在路径规划过程中，确保无人船在复杂环境下能够安全、高效地执行任务。改进的DWA算法有效结合了这些约束，避免了过急转弯或不必要的减速，从而确保无人船能够稳定、精确地按照全局路径前进。
