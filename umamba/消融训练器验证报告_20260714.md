## 潜在问题排查

### 如果出现导入错误
```bash
# 检查网络定义文件
ls -la nnunetv2/nets/UMambaEnc_RTHD.py

# 检查函数是否存在
grep "def get_umamba_enc_rthd_3d_from_plans" nnunetv2/nets/UMambaEnc_RTHD.py
```

### 如果出现配置错误
- 检查 `rthd_stages_decoder=[]` 确保解码器不使用ETSM
- 检查 `skip_gate_stages=[0, 1]` 确保跳跃标定在正确阶段
- 检查 `skip_gate_type="semantic"` 确保使用语义门控

### 如果出现OOM
- 减小batch size（但会影响对比公平性）
- 使用梯度检查点（如果尚未启用）
- 检查是否有其他进程占用显存
