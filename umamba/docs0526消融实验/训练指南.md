## 🚀 使用方法

### 基础命令格式

```bash
nnUNetv2_train DATASET_ID CONFIG FOLD -tr TRAINER_NAME
```

### 具体示例（假设 BraTS 数据集 ID 为 137）

#### 1. 运行基础版（默认配置）

```bash
# 消融实验 #2: 单视图降级版
nnUNetv2_train 137 3d_fullres 0 -tr nnUNetTrainerUMambaEncRTHD_Ablation2_SingleView

# 消融实验 #3: 独立参数版
nnUNetv2_train 137 3d_fullres 0 -tr nnUNetTrainerUMambaEncRTHD_Ablation3_IndependentWeights

# 消融实验 #4: 常规扫描版
nnUNetv2_train 137 3d_fullres 0 -tr nnUNetTrainerUMambaEncRTHD_Ablation4_StandardScan

# 消融实验 #5: 全局平铺版
nnUNetv2_train 137 3d_fullres 0 -tr nnUNetTrainerUMambaEncRTHD_Ablation5_GlobalFlatten

# 消融实验 #6: 完整创新版（推荐）
nnUNetv2_train 137 3d_fullres 0 -tr nnUNetTrainerUMambaEncRTHD_Ablation6_FullInnovation
```

#### 2. 运行 350 Epochs 版（推荐用于正式实验）



## ⚙️ 训练配置说明

### 350 Epochs + Patience 50 版本特性

- **最大训练轮数**: 350 epochs
- **早停机制**: Patience 50
  - 如果连续 50 个 epoch 验证集 Dice 没有提升，自动停止训练
  - 避免过拟合，节省训练时间
- **监控指标**: EMA (Exponential Moving Average) Dice
- **自动保存**: 最佳模型会自动保存

### 早停日志示例

```
Epoch 150: No improvement in EMA dice. Patience: 1/50
Epoch 151: No improvement in EMA dice. Patience: 2/50
...
Epoch 199: No improvement in EMA dice. Patience: 50/50
Early stopping triggered at epoch 199
```

## 🔍 故障排查

### 1. 显存不足 (OOM)

**症状**: `RuntimeError: CUDA out of memory`

**解决方案**:
- 减小 batch size（在 plans 文件中修改）
- 使用梯度累积
- 减小 patch size

### 2. 导入错误

**症状**: `ModuleNotFoundError: No module named 'nnunetv2'`

**解决方案**:
```bash
cd umamba
pip install -e .
```

### 3. SS2D 导入失败

**症状**: `Warning: Cannot import SS2D from vmamba module`

**解决方案**:
- 检查 `umamba/instructions/vmamba.py` 是否存在
- 会自动使用占位符 Conv2d，功能正常但性能略差
