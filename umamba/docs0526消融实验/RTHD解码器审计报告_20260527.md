#### 数据流分析

```
Step 1: 上采样
  lres_input (C_below) → UpsampleLayer → x (C_skip)

Step 2: 跳跃连接拼接
  x (C_skip) + skips[-(s+2)] (C_skip) → torch.cat → x (2 * C_skip)
  
Step 3: BasicResBlock 降维 ✅
  x (2C) → BasicResBlock(input=2C, output=C, use_1x1conv=True) → x (C)
  
Step 4: RTHD 处理
  x (C) → RTHDBlock(dim=C) → x (C)
```

#### 安全性验证

✅ **BasicResBlock 的 `use_1x1conv=True` 参数确保了通道降维**

查看 `BasicResBlock` 的实现（第 110-148 行）：


```
编码器 Stage 0: RTHDBlock_enc_0 (dim=32)

  └─ TriViewVMambaBlock (dim=64)
```

- ✅ 每个 `RTHDBlock` 都有自己独立的 `TriViewVMambaBlock` 实例
- ✅ 权重共享只在单个 block 内部的三个视图之间

1. **通道降维机制**：
   - 使用 `BasicResBlock(input_channels=2C, output_channels=C, use_1x1conv=True)`
   - 在 `torch.cat` 之后、`RTHDBlock` 之前完成降维

3. **参数对齐保证**：
   - 编码器：`dim = features_per_stage[s]`
   - 解码器：`dim = input_features_skip`（降维后）
   - 两者都与实际张量通道数严格对齐

### 关键代码段 1：解码器 forward 流程

**文件**: `UMambaEnc_RTHD.py`  
**行号**: 559-570

```python
def forward(self, skips):
    lres_input = skips[-1]
    seg_outputs = []
    for s in range(len(self.stages)):
        # Step 1: 上采样
        x = self.upsample_layers[s](lres_input)  # C_below → C_skip
        
        # Step 2: 拼接（通道翻倍）
        x = torch.cat((x, skips[-(s+2)]), 1)  # C + C → 2C
        
        # Step 3: 通过 stage（包含降维）
        x = self.stages[s](x)  # 2C → C (BasicResBlock 降维) → C (RTHDBlock)
        
        if self.deep_supervision:
            seg_outputs.append(self.seg_layers[s](x))
        elif s == (len(self.stages) - 1):
            seg_outputs.append(self.seg_layers[-1](x))
        lres_input = x
```

### 关键代码段 2：BasicResBlock 降维逻辑

**文件**: `UMambaEnc_RTHD.py`  
**行号**: 110-148

```python
class BasicResBlock(nn.Module):
    def __init__(self, ..., input_channels, output_channels, ..., use_1x1conv=False):
        super().__init__()
        
        self.conv1 = conv_op(input_channels, output_channels, 
                            kernel_size, stride=stride, padding=padding)
        self.norm1 = norm_op(output_channels, **norm_op_kwargs)
        self.act1 = nonlin(**nonlin_kwargs)
        
        self.conv2 = conv_op(output_channels, output_channels, 
                            kernel_size, padding=padding)
        self.norm2 = norm_op(output_channels, **norm_op_kwargs)
        self.act2 = nonlin(**nonlin_kwargs)
        
        if use_1x1conv:
            # 关键：1x1 卷积用于降维和残差连接
            self.conv3 = conv_op(input_channels, output_channels, 
                                kernel_size=1, stride=stride)
        else:
            self.conv3 = None
    
    def forward(self, x):
        y = self.conv1(x)  # input_channels → output_channels
        y = self.act1(self.norm1(y))
        y = self.norm2(self.conv2(y))
        if self.conv3:
            x = self.conv3(x)  # 降维：input_channels → output_channels
        y += x  # 残差连接
        return self.act2(y)
```
