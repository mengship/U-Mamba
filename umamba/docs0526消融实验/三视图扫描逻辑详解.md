# RTHD 三视图扫描逻辑与解剖学对应分析

## 📊 当前实现的扫描逻辑

### 1. 三维张量的维度定义

在代码中，3D 特征张量的形状为 `(B, C, D, H, W)`：

```python
# 医学图像的标准坐标系
D (Depth)  = 深度维度 = 上下方向 (Superior-Inferior)
H (Height) = 高度维度 = 前后方向 (Anterior-Posterior)  
W (Width)  = 宽度维度 = 左右方向 (Left-Right)
```

**注意**：这个对应关系取决于数据预处理时的坐标系定义。

## 🔬 三视图投影的实际实现

### 代码实现（rthd_modules.py 第 111-113 行）

```python
# 输入: (B, C, D, H, W)

axial = x.mean(dim=2)      # (B, C, H, W) - 沿 D 维度平均
coronal = x.mean(dim=3)    # (B, C, D, W) - 沿 H 维度平均  
sagittal = x.mean(dim=4)   # (B, C, D, H) - 沿 W 维度平均
```

### 解剖学对应

| 视图 | 投影操作 | 保留维度 | 消除维度 | 解剖学含义 |
|-----|---------|---------|---------|-----------|
| **Axial** | `mean(dim=2)` | H × W | D | 水平切面（横断面），看到左右+前后 |
| **Coronal** | `mean(dim=3)` | D × W | H | 冠状切面，看到上下+左右 |
| **Sagittal** | `mean(dim=4)` | D × H | W | 矢状切面，看到上下+前后 |

## 🎯 扫描方向分析

### 当前实现：全向扫描（omni mode）

在 `scan_mode='omni'` 时，SS2D 对每个 2D 视图进行 **4 方向扫描**：

```python
# 对于任意 2D 特征图 (B, C, H, W)
方向 1: 水平正向 (→)  - 沿 W 维度从左到右
方向 2: 水平反向 (←)  - 沿 W 维度从右到左
方向 3: 垂直正向 (↓)  - 沿 H 维度从上到下
方向 4: 垂直反向 (↑)  - 沿 H 维度从下到上
```

### 三视图的扫描方向对应

#### 1. Axial 视图 (H × W)

**保留维度**：H (前后) × W (左右)

**4 方向扫描**：
```
方向 1 (→): 沿 W 维度 = 从左到右扫描
方向 2 (←): 沿 W 维度 = 从右到左扫描
方向 3 (↓): 沿 H 维度 = 从前到后扫描
方向 4 (↑): 沿 H 维度 = 从后到前扫描
```

**解剖学意义**：
- 捕获左右方向的依赖（如左右脑半球的对称性）
- 捕获前后方向的依赖（如额叶到枕叶的连续性）

#### 2. Coronal 视图 (D × W)

**保留维度**：D (上下) × W (左右)

**4 方向扫描**：
```
方向 1 (→): 沿 W 维度 = 从左到右扫描
方向 2 (←): 沿 W 维度 = 从右到左扫描
方向 3 (↓): 沿 D 维度 = 从上到下扫描
方向 4 (↑): 沿 D 维度 = 从下到上扫描
```

**解剖学意义**：
- 捕获左右方向的依赖
- 捕获上下方向的依赖（如大脑皮层到脑干的连续性）

#### 3. Sagittal 视图 (D × H)

**保留维度**：D (上下) × H (前后)

**4 方向扫描**：
```
方向 1 (→): 沿 H 维度 = 从前到后扫描
方向 2 (←): 沿 H 维度 = 从后到前扫描
方向 3 (↓): 沿 D 维度 = 从上到下扫描
方向 4 (↑): 沿 D 维度 = 从下到上扫描
```

**解剖学意义**：
- 捕获前后方向的依赖
- 捕获上下方向的依赖

## 🌐 完整的 3D 方向覆盖

### 三视图 × 全向扫描 = 完整 3D 建模

| 解剖学方向 | Axial 视图 | Coronal 视图 | Sagittal 视图 |
|-----------|-----------|-------------|--------------|
| **左右 (L-R)** | ✓ (方向 1,2) | ✓ (方向 1,2) | ✗ (已投影) |
| **前后 (A-P)** | ✓ (方向 3,4) | ✗ (已投影) | ✓ (方向 1,2) |
| **上下 (S-I)** | ✗ (已投影) | ✓ (方向 3,4) | ✓ (方向 3,4) |

**关键发现**：
- 每个 3D 方向都被**至少 2 个视图**覆盖
- 通过三视图融合，实现了**完整的 3D 全向建模**
- 这种设计是**有意为之**，确保没有方向被遗漏

## 💡 与你的分析对比

### 你的第一种理解

> Axial → H×W → 左右扫描  
> Coronal → D×W → 前后扫描  
> Sagittal → D×H → 上下扫描

**评价**：❌ 不完全准确

**原因**：每个视图不是只扫描一个方向，而是在保留的 2D 平面上进行**4 方向全向扫描**。

### 你的第二种理解

> Axial → H×W → 前后扫描  
> Coronal → D×W → 上下扫描  
> Sagittal → D×H → 左右扫描

**评价**：❌ 也不完全准确

**原因**：同样，每个视图是 4 方向扫描，不是单一方向。

### 正确的理解

**每个视图都进行 4 方向扫描**：

- **Axial (H×W)**：扫描前后 + 左右（4 个方向）
- **Coronal (D×W)**：扫描上下 + 左右（4 个方向）
- **Sagittal (D×H)**：扫描上下 + 前后（4 个方向）

**融合后**：覆盖所有 3D 方向（左右、前后、上下）

---

## 🔍 为什么这样设计？

### 1. **避免方向偏见**

如果每个视图只扫描一个方向：
- ❌ 某些方向可能被忽略
- ❌ 模型会有方向偏见

使用全向扫描：
- ✓ 每个视图内部就是全向的
- ✓ 三视图融合后更加完整

### 2. **医学图像的特点**

脑肿瘤可能：
- 沿任意方向生长
- 有不规则的形状
- 需要全方向的上下文信息

### 3. **与 Swin Transformer 的区别**

**Swin Transformer**：
- 使用窗口注意力
- 通过窗口移位实现跨窗口交互

**RTHD**：
- 使用三视图分解
- 每个视图内全向扫描
- 通过视图融合实现 3D 建模

## 📊 消融实验的意义

**效果**：
- 每个视图扫描 4-8 个方向
- 完整捕获所有方向的依赖
- 最佳性能

## 🎯 总结

### 当前实现的扫描逻辑

1. **三视图投影**：将 3D 分解为 3 个 2D 视图
2. **全向扫描**：每个 2D 视图进行 4 方向扫描
3. **视图融合**：将 3 个视图的特征融合回 3D

### 解剖学覆盖

| 3D 方向 | 覆盖情况 |
|--------|---------|
| 左右 (L-R) | Axial + Coronal |
| 前后 (A-P) | Axial + Sagittal |
| 上下 (S-I) | Coronal + Sagittal |

**结论**：✓ 完整覆盖所有 3D 方向，没有遗漏

### 设计优势

1. ✓ **完整的 3D 建模**：三视图 × 全向扫描
2. ✓ **无方向偏见**：每个方向都被充分建模
3. ✓ **计算高效**：2D 扫描比 3D 扫描快得多
4. ✓ **显存友好**：序列长度从 O(D×H×W) 降至 O(H×W)
