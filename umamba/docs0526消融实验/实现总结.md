## 🔧 核心修改

### 1. 新增局部滑窗机制

在 `rthd_modules.py` 中添加了两个关键函数：

- **`window_partition(x, window_size)`**: 将 2D 特征图分割为不重叠的局部窗口
- **`window_reverse(windows, window_size, H_pad, W_pad, H_orig, W_orig)`**: 将窗口特征合并回完整特征图

这实现了 LoMamba 的局部滑窗思想，减少序列长度，提高计算效率。

### 2. 重构 `TriViewVMambaBlock`

添加了 4 个消融控制参数：

```python
view_mode: str = 'tri'           # 'tri' (三视图) 或 'single' (仅轴状位)
share_weights: bool = True       # True (参数共享) 或 False (独立参数)
scan_mode: str = 'omni'          # 'omni' (全向扫描) 或 'standard' (标准扫描)
use_local_window: bool = False   # True (局部滑窗) 或 False (全局平铺)
window_size: int = 8             # 局部窗口大小
```

**关键实现逻辑**：

- **单视图模式** (#2): 只处理轴状位，通过 `unsqueeze` 和 `expand` 还原 3D 维度
- **独立参数** (#3): 实例化三个独立的 Mamba 模块（`vmamba_axial`, `vmamba_coronal`, `vmamba_sagittal`）
- **标准扫描** (#4): 通过 `forward_type='v0'` 切换到标准双向扫描
- **局部滑窗** (#3, #4, #6): 使用 `window_partition` 和 `window_reverse` 实现分窗处理

### 3. 更新 `RTHDBlock`

将消融控制参数传递给 `TriViewVMambaBlock`，确保配置在整个模块中生效。

### 4. 修改 `UMambaEnc_RTHD` 和 `ResidualMambaEncoder_RTHD`

- 添加 `rthd_config` 参数接收消融实验配置
- 在创建 `RTHDBlock` 时传递配置参数
- 更新 `get_umamba_enc_rthd_3d_from_plans` 函数支持自定义配置

```bash

# 实验 #3: 独立参数版
nnUNetv2_train DATASET_ID CONFIG FOLD -tr nnUNetTrainerUMambaEncRTHD_Ablation3_IndependentWeights

# 实验 #4: 常规扫描版
nnUNetv2_train DATASET_ID CONFIG FOLD -tr nnUNetTrainerUMambaEncRTHD_Ablation4_StandardScan

# 实验 #5: 全局平铺版（当前已运行）

nnUNetv2_train DATASET_ID CONFIG FOLD -tr nnUNetTrainerUMambaEncRTHD_Ablation6_FullInnovation
```

### 自定义配置

如果需要自定义配置，可以在 Trainer 中修改 `rthd_config` 字典：

```python
rthd_config = {
    'view_mode': 'tri',           # 'tri' or 'single'
    'share_weights': True,        # True or False
    'scan_mode': 'omni',          # 'omni' or 'standard'
    'use_local_window': True,     # True or False
    'window_size': 8,             # 窗口大小
}
```
