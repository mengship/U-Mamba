## 三、新增参数

### 3.1 UNetResDecoder_RTHD 类

新增参数：

```python
decoder_rthd_mode: str = "full"
```
- **类型**: `str`
- **可选值**: `"none"`, `"partial"`, `"full"`
- **默认值**: `"full"`
- **含义**:
  - `"none"`: 不使用RTHD解码器，回退到原始卷积解码器
  - `"partial"`: 部分stage使用RTHD块
  - `"full"`: 所有stage使用RTHD块（默认，保持向后兼容）

```python
rthd_stages_decoder: List[int] = None
```
- **类型**: `List[int]`
- **默认值**: `None` (当`decoder_rthd_mode="partial"`时，默认为`[0, 1]`)
- **含义**: 指定解码器中哪些stage使用RTHD块（仅在`decoder_rthd_mode="partial"`时生效）

### 3.2 UMambaEnc_RTHD 类

保留原有参数：
```python
rthd_config: dict = None  # 统一配置（向后兼容）
use_rthd_decoder: bool = True  # 向后兼容参数
```

新增参数：
```python
rthd_config_encoder: dict = None  # 编码器专用配置
rthd_config_decoder: dict = None  # 解码器专用配置
decoder_rthd_mode: str = "full"  # 解码器RTHD模式
rthd_stages_decoder: List[int] = None  # 解码器RTHD stage列表
```

## 四、实现逻辑详解

### 4.1 Partial Decoder RTHD 实现

#### 核心逻辑

在 `UNetResDecoder_RTHD.__init__` 中：

```python
# 确定哪些decoder stage使用RTHD
if decoder_rthd_mode == "none":
    self.rthd_stages_decoder = []
elif decoder_rthd_mode == "partial":
    if rthd_stages_decoder is None:
        self.rthd_stages_decoder = [0, 1]  # 默认前两个stage
    else:
        self.rthd_stages_decoder = rthd_stages_decoder
elif decoder_rthd_mode == "full":
    self.rthd_stages_decoder = list(range(n_stages_encoder - 1))
```

#### Stage构造逻辑

在构造每个decoder stage时：

```python
for s in range(1, n_stages_encoder):
    decoder_stage_idx = s - 1
    use_rthd_this_stage = decoder_stage_idx in self.rthd_stages_decoder
    
    if use_rthd_this_stage:
        # 构造：BasicResBlock + RTHDBlock + 额外的BasicBlockD
        stage_blocks = [
            BasicResBlock(...),
            RTHDBlock(...),
            # 额外的BasicBlockD（如果n_conv_per_stage > 2）
        ]
    else:
        # 构造：BasicResBlock + 额外的BasicBlockD（不使用RTHD）
        stage_blocks = [
            BasicResBlock(...),
            # 额外的BasicBlockD（如果n_conv_per_stage > 1）
        ]
```

### 4.2 Encoder/Decoder 配置分离实现

#### 配置回退逻辑

在 `UMambaEnc_RTHD.__init__` 中实现了三级回退机制：

```python
# 编码器配置优先级：rthd_config_encoder -> rthd_config -> {}
final_encoder_config = rthd_config_encoder if rthd_config_encoder is not None \
                       else (rthd_config if rthd_config is not None else {})

# 解码器配置优先级：rthd_config_decoder -> rthd_config -> {}
final_decoder_config = rthd_config_decoder if rthd_config_decoder is not None \
                       else (rthd_config if rthd_config is not None else {})
```

#### 配置传递

```python
# 编码器使用专用配置
self.encoder = ResidualMambaEncoder_RTHD(
    ...,
    rthd_config=final_encoder_config,
)

# 解码器使用专用配置
self.decoder = UNetResDecoder_RTHD(
    ...,
    rthd_config=final_decoder_config,
    decoder_rthd_mode=decoder_rthd_mode,
    rthd_stages_decoder=rthd_stages_decoder,
)
```

### 4.3 向后兼容性处理

#### 兼容 use_rthd_decoder 参数

```python
# use_rthd_decoder=False 等价于 decoder_rthd_mode="none"
if not use_rthd_decoder:
    decoder_rthd_mode = "none"

if decoder_rthd_mode == "none":
    # 使用原始卷积解码器
    self.decoder = UNetResDecoder(...)
else:
    # 使用RTHD解码器
    self.decoder = UNetResDecoder_RTHD(...)
```

#### 兼容统一 rthd_config 参数

如果只提供 `rthd_config`，则编码器和解码器都使用该配置，保持原有行为。

## 六、使用示例

### 示例1：使用统一配置（向后兼容）

```python
model = UMambaEnc_RTHD(
    ...,
    rthd_config={
        'view_mode': 'tri',
        'share_weights': True,
        'scan_mode': 'omni',
    },
    # decoder默认使用"full"模式，与encoder配置相同
)
```

### 示例2：部分解码器使用RTHD

```python
model = UMambaEnc_RTHD(
    ...,
    decoder_rthd_mode="partial",
    rthd_stages_decoder=[0, 1],  # 只在前两个decoder stage使用RTHD
)
```

### 示例3：编码器和解码器使用不同配置

```python
model = UMambaEnc_RTHD(
    ...,
    rthd_config_encoder={
        'view_mode': 'tri',
        'share_weights': True,
        'scan_mode': 'omni',
    },
    rthd_config_decoder={
        'view_mode': 'tri',
        'share_weights': False,
        'scan_mode': 'standard',
    },
    decoder_rthd_mode="partial",
    rthd_stages_decoder=[0, 1, 2],
)
```

### 示例4：不使用RTHD解码器

```python
model = UMambaEnc_RTHD(
    ...,
    decoder_rthd_mode="none",
    # 或者使用向后兼容参数：use_rthd_decoder=False
)
```
