## 需要修复的问题

### 问题 1：cross-view interaction 会系统性压低特征幅值

当前 `rthd_modules.py` 里的 `_apply_cross_view_interaction()` 做法是：

- 先生成 `sigmoid` gate
- 再直接：
  - `axial_refined = axial * gate_axial`
  - `coronal_refined = coronal * gate_coronal`
  - `sagittal_refined = sagittal * gate_sagittal`

这会导致 gate 初值接近 `0.5` 时，把三个视图整体压小，属于明显的行为回归。

### 修复要求

请把 cross-view interaction 改成更稳的残差式门控，推荐形式之一：

- `x * (1 + gate)`
- 或 `x + x * gate`

总之目标是：

- 初始状态尽量接近 identity
- 不要默认削弱特征幅值

如果你认为需要，也可以对 gate logits 的初始化做轻量处理，但不要引入复杂初始化系统。

### 问题 2：interaction 参数接口不安全

当前公开暴露了：

- `cross_view_interaction`
- `interaction_mode`
- `interaction_type`

但实际上第一版只支持：

- `cross_view_interaction=True`

如果传入别的组合，现在构造阶段可能把 `self.interaction_gate_conv = None`，但 forward 里仍然会调用它，导致运行时错误。

### 修复要求

#### 方案 A：严格校验参数
在 `__init__` 中直接检查：

#### 方案 B：收缩接口
