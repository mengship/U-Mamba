## 三、必须实现的功能

### 功能 A：Partial Decoder RTHD

当前 `UNetResDecoder_RTHD` 的逻辑是：

- 所有 decoder stage 都固定使用 `RTHDBlock`

这次请改成支持三种模式：

```python
decoder_rthd_mode: str = "full"   # "none", "partial", "full"
```

语义要求：

- `"none"`
  不使用 RTHD 解码器，回退到原始 `UNetResDecoder`

- `"partial"`
  解码器只在部分 stage 使用 `RTHDBlock`

- `"full"`
  保持当前完全对称版本

### 功能 B：支持 `rthd_stages_decoder`

新增参数：

```python
rthd_stages_decoder: List[int] = None
```

含义：

- 指定 decoder 中哪些 stage 使用 `RTHDBlock`

要求：

- 仅当 `decoder_rthd_mode == "partial"` 时生效
- 如果未显式提供，可给一个合理默认值
- 推荐默认只在 decoder 前两个 stage 使用 RTHD，例如 `[0, 1]`

### 功能 C：Encoder / Decoder 分离配置

当前代码里 encoder 和 decoder 共用同一个：

```python
rthd_config
```

这次请改成支持：

```python
rthd_config_encoder: dict = None
rthd_config_decoder: dict = None
```

要求：

- 如果用户只传 `rthd_config`
  则 encoder 和 decoder 都沿用它，保持兼容

- 如果用户传了 `rthd_config_encoder`
  则 encoder 使用它

- 如果用户传了 `rthd_config_decoder`
  则 decoder 使用它

- 若两者都传，则不要再强制共用统一配置


## 四、建议修改位置
