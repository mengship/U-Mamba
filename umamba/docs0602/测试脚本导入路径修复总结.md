## 修复详情

### 修复前（有问题）

```python
# 错误的路径设置
current_dir = os.path.dirname(os.path.abspath(__file__))
sys.path.insert(0, current_dir)  # 指向 script 目录，错误！
```

**问题：**
- `current_dir` 指向 `.../umamba/docs0602/script`
- 但 `nnunetv2` 模块在 `.../umamba/` 下
- 导致 `from nnunetv2.nets.rthd_modules import ...` 失败

### 修复后（正确）

```python
# 正确的路径设置
current_dir = os.path.dirname(os.path.abspath(__file__))
# current_dir: .../umamba/docs0602/script
umamba_dir = os.path.dirname(os.path.dirname(current_dir))
# umamba_dir: .../umamba
sys.path.insert(0, umamba_dir)
```

**路径计算：**
```
__file__:     .../umamba/docs0602/script/test_rthd_v1_enhancements.py
current_dir:  .../umamba/docs0602/script
parent:       .../umamba/docs0602
umamba_dir:   .../umamba
```

现在 `sys.path[0]` 指向 umamba 目录，可以正确导入 `nnunetv2` 模块。
