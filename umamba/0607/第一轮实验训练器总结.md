## 二、新创建训练器（150 epochs for 第一轮筛选）

### 2.1 EncoderOnly (编码器RTHD基线)
**基础版本**: `nnUNetTrainerUMambaEncRTHD_EncoderOnly`  
**150 epochs版本**: `nnUNetTrainerUMambaEncRTHD_EncoderOnly_150epochs`

**配置**:
- Encoder: RTHD enabled (tri-view, omni-scan, gated reconstruction, local window)
- Decoder: Standard convolution (no RTHD)
- Skip fusion gate: disabled
- Boundary attention: disabled
- Frequency refinement: disabled

**实验目的**: 验证 Encoder RTHD 对全局建模的有效性（作为解码器增强的baseline）

---

### 2.2 StageAwareDecoder (阶段感知解码器)
**基础版本**: `nnUNetTrainerUMambaEncRTHD_StageAwareDecoder` (已修改)  
**150 epochs版本**: `nnUNetTrainerUMambaEncRTHD_StageAwareDecoder_150epochs` (新增)

**配置**:
- Encoder: RTHD enabled
- Decoder: Stage-aware RTHD deployment (partial mode)
  - Low-resolution stages (D4/D3): RTHD
  - High-resolution stages (D2/D1): Standard convolution
- Skip fusion gate: disabled (留给SkipCalibration)
- Boundary attention: disabled (留给Full Model)
- Frequency refinement: disabled

**实验目的**: 验证阶段感知解码器部署策略的有效性

**修改说明**: 原 StageAwareDecoder 默认启用了所有第二版增强，现已修改为基础版本（关闭skip gate和boundary attention）

---

### 2.3 SkipCalibration (跳跃连接特征校准)
**基础版本**: `nnUNetTrainerUMambaEncRTHD_StageAwareDecoder_SkipCalibration` (新增)  
**150 epochs版本**: `nnUNetTrainerUMambaEncRTHD_StageAwareDecoder_SkipCalibration_150epochs` (新增)

**配置**:
- 继承 StageAwareDecoder 配置
- Skip fusion gate: enabled (stages [0, 1], reduction=4)
- Boundary attention: disabled (留给Full Model)
- Frequency refinement: disabled

**实验目的**: 验证语义引导的跳跃连接特征校准（Skip Calibration）的有效性

---

### 2.4 Full Model (完整模型)
**基础版本**: `nnUNetTrainerUMambaEncRTHD_StageAwareDecoder_Full` (新增)  
**150 epochs版本**: `nnUNetTrainerUMambaEncRTHD_StageAwareDecoder_Full_150epochs` (新增)

**配置**:
- 继承 SkipCalibration 配置
- Skip fusion gate: enabled
- Boundary attention: enabled (final decoder stage)
- Frequency refinement: disabled (不作为主模型，仅保留为可选消融)

**实验目的**: 验证完整的阶段感知解码器恢复策略

**论文主模型名称**: RTHD-StageAwareDecoder-Full

---

## 三、第一轮推荐运行顺序 (fold 0, 150 epochs)

## 四、训练命令示例

所有实验统一使用 **fold 0, 150 epochs**：

```bash
# 1. EncoderOnly (编码器RTHD基线)
nnUNetv2_train DATASET_ID 3d_fullres 0 \
    -tr nnUNetTrainerUMambaEncRTHD_EncoderOnly_150epochs

# 2. StageAwareDecoder (阶段感知解码器)
nnUNetv2_train DATASET_ID 3d_fullres 0 \
    -tr nnUNetTrainerUMambaEncRTHD_StageAwareDecoder_150epochs

# 3. SkipCalibration (跳跃连接校准)
nnUNetv2_train DATASET_ID 3d_fullres 0 \
    -tr nnUNetTrainerUMambaEncRTHD_StageAwareDecoder_SkipCalibration_150epochs

# 4. Full Model (完整模型)
nnUNetv2_train DATASET_ID 3d_fullres 0 \
    -tr nnUNetTrainerUMambaEncRTHD_StageAwareDecoder_Full_150epochs

# 可选：原始RTHD baseline
nnUNetv2_train DATASET_ID 3d_fullres 0 \
    -tr nnUNetTrainerUMambaEncRTHD
```

## 五、实验对比表

| 训练器简称 | Encoder RTHD | Decoder RTHD部署 | Skip Gate | Boundary Attn | 实验目的 |
|-----------|-------------|----------------|-----------|--------------|---------|
| EncoderOnly | ✓ | None | - | - | 验证编码器RTHD全局建模 |
| StageAwareDecoder | ✓ | Partial (D4/D3) | - | - | 验证阶段感知解码器 |
| SkipCalibration | ✓ | Partial (D4/D3) | ✓ | - | 验证跳跃连接校准 |
| Full | ✓ | Partial (D4/D3) | ✓ | ✓ | 完整模型（论文主模型） |

**说明**:
- Decoder RTHD部署: Partial = 低分辨率stages (D4/D3)使用RTHD，高分辨率stages (D2/D1)使用卷积
- Skip Gate: 语义引导跳跃连接融合门控 (stages [0, 1])
- Boundary Attn: 边界感知注意力头 (final decoder stage)
- Frequency Refinement: 所有实验中均不启用（仅保留为可选消融）

## 八、论文贡献链

### 渐进增强策略

```
Baseline (U-Mamba)
    ↓
+ Encoder RTHD (EncoderOnly)
    ↓ [贡献1: 编码器全局建模]
+ Stage-aware Decoder (StageAwareDecoder)
    ↓ [贡献2: 阶段感知解码器部署]
+ Skip Calibration (SkipCalibration)
    ↓ [贡献3: 语义引导跳跃连接校准]
+ Boundary Refinement (Full)
    ↓ [贡献4: 边界感知特征增强]
Final Model: RTHD-StageAwareDecoder-Full
```

### 论文描述

**模型名称**: RTHD-StageAwareDecoder-Full

**方法描述**: 本文在解码阶段设计阶段感知的结构恢复策略，通过低分辨率RTHD refinement建模全局结构、语义引导跳连融合恢复局部细节，并结合边界注意力增强肿瘤轮廓质量。
